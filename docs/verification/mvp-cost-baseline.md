- 单期总成本 $0.36 接近需求目标线 $0.5，在预算内

## 成本结构结论

- **复核 > 转写 > 翻译**：复核用同档强模型且输入含原文+译文双份，token 量与单价都最高。这是质量优先的刻意代价，不建议为省钱降低复核模型档位（skill pitfalls 实测：快模型复核只改一处就报完成，强模型改 37/110 条）
- 翻译极便宜（flash，$0.0175），无需优化
- 转写成本与音频时长线性相关，长节目（>50 分钟）会推高总成本逼近 $0.5 线，需按实际时长监控

## 一次真实教训（格式错误的代价）

- 首次翻译（v1）因子代理输出三段式（非 `编号<TAB>译文`）格式错误，产物不可用，但仍计费 $0.0236
- 修正 prompt + 输入转 TAB 形态后重跑（v2）成功，$0.0175
- 教训：**子代理输出契约必须在 prompt 里硬性约束 + 输入预处理**（SRT→TAB），否则付费调用产出不可用即浪费。该格式校验已被 apply 的「纯标点/缺行/重号」检查兜底

## 对后续阶段的指导

- 自动化主链的分类过滤（< $0.005/期）相对单期 $0.36 可忽略，成本闸门价值在于**避免无关节目进入转写+复核**
- 账本已覆盖转写/翻译/复核；调研本期未启用（专名自拟），其成本待首次调研时补基线
- 长节目成本监控：复核输入随条目数增长，超长节目（>1200 条）触发分块降级时需重新核算复核成本
